About

私たちについて

思想を伝えるだけで、終わらせない。
人と組織が本来持っている価値を見つけ、必要な人へ届き続ける土台を、一緒に整えます。

Definition

Base Craftasとは

人と組織が、本来の価値を発揮し続けるための土台を整える事業体です。

専門職が積み重ねてきた知識や経験。経営者が事業を通じて実現したい想い。組織の中に蓄積された技術やノウハウ。地域で長く育まれてきた信頼や関係性。

価値があることと、その価値が必要な人へ届いていることは、同じではありません。言葉になっていない、伝える手段が整っていない、日々の業務に追われている、働く人の心身に余裕がない。こうした理由で、本来ある価値が十分に発揮されていないことがあります。

Base Craftasは、すでにある価値を整理し、言葉、発信、導線、仕組み、健康、教育、現場支援へ変換します。価値を外から付け加えるのではなく、その人や組織が持つものを、社会へ届き続ける形に整えます。

Background

私たちが向き合う課題

Base Craftasが向き合うのは、「価値がない」という問題ではありません。価値があるにもかかわらず、十分に発揮されていない状態です。

Value
専門性や想いが、伝わる形になっていない
医療、健康、福祉、地域の事業には、積み重ねてきた専門性や信頼があります。その本質を保ったまま、必要な人へ伝わる言葉・発信・導線へ翻訳します。
Focus
本来の仕事に使う時間が失われている
転記、集計、二重入力、属人化、情報の分散。業務を見直すことは人を減らすことではなく、人にしかできない仕事へ時間と力を戻すことだと考えています。
Health
働く人の不調が、個人の問題として扱われている
腰痛、肩こり、睡眠不足、疲労、ストレス。小さな不調を本人だけの責任にせず、組織として健康な土台を支えられる環境を整えます。
Learning
現場で人を育てる余白が不足している
日々の業務に追われ、スタッフ教育や研修、新しい知識を取り入れる時間を確保できない現場へ、専門職による臨床・教育・業務改善の機会を届けます。
Mission / Vision / Value
Mission
人と組織が、本来の価値を発揮し続けられる土台を整える。
専門性、経験、想い、技術、地域性、関係性。すでに存在している価値に光を当て、必要な人へ届く形に変えていきます。一時的に伝わるだけではなく、仕組みや習慣、文化として根づく状態をつくります。
Vision
誰もが自分の選択に納得し、健康な土台の上で価値を発揮できる社会をつくる。
人は、自分に合った情報、環境、働き方、支援、専門家と出会うことで、本来の力を発揮しやすくなります。組織もまた、経営資源を適切に使い、働く人の健康を守り、人材が育つ環境を整えることで、本来の価値提供に集中できます。

Our Style

私たちが大切にする支援のあり方

答えを押しつけない

その人や組織が何を大切にしているのか、どのような価値を社会へ届けたいのか。対話を通じて、一緒に整理します。

手段から考えない

SNS、AI、業務改善、健康経営、研修はすべて手段です。まず「何を実現したいのか」から考え、必要な方法を選びます。

現場で使える形まで整える

構想や提案だけで終わらせず、資料、発信、導線、業務フロー、研修、教育、実践まで落とし込みます。

一過性で終わらせない

Base Craftasがいなくても、人と組織が自ら考え、動き、育ち続けられるよう、仕組みと学びが残る支援を目指します。
