# ToToNoE+ IROHA

有料学習サービスIROHAのローカルUI・データ設計プロトタイプです。既存の公開コンテンツページとは分離し、公開ナビゲーションからはリンクしていません。

## 現在できること

- 料金ページで月額・年額と一般・セラピスト料金を切り替える
- 日曜始まり・土曜終わりの週間学習プランを表示する
- 土曜日に次週の予定が未設定なら、2〜3日の選択を必須ポップアップで案内する
- 1週間の総学習時間を先に確定し、その後に曜日を2〜3日選び、曜日ごとの時間を1分単位で配分してブラウザ内に仮保存する
- 曜日選択時は「総時間 ÷ 選択日数」の1日目安を表示し、時間配分画面では均等案から自由に比重を変更できる
- 学習実績を1分単位で記録し、週の予定時間に対する進捗を表示する
- 土曜日は「今週の実績・学び・障害」を振り返り、SMARTな次週目標とIf–Then実行プランを保存してから次週計画へ進む
- 学習時間と週次レビューはマイページに履歴として蓄積し、旧ORID記録も読み取り専用で表示する
- Drive動画URLからファイルIDを抽出し、ツール・レベル・公開範囲・制作状態と一緒に教材台帳へ仮保存する
- 公開時は動画登録・公開権利・対象会員での閲覧確認を必須にする
- Drive動画の受講画面と、手動の視聴完了・実務アクション記録を確認する
- レッスン開始・完了、ツール別カリキュラム選択の画面を確認する
- ChatGPT・Claude・Geminiの公式ロゴと初期カリキュラム構成を表示する
- D1向けの会員・契約・資格確認・学習進捗スキーマを確認する
- 相談特典を法人研修プラン公開後に解放し、担当者の30分枠へ接続する構造を確認する

## まだ接続していないもの

- 本番ログイン、メール認証、権限制御
- Stripe等の決済・Webhook・請求管理
- セラピスト資格画像のR2アップロードと審査
- 実際のDriveフォルダ作成・共有権限変更・Drive API同期
- D1への実データ保存
- 30分相談枠の予約サービス
- 公開サイトのナビゲーション

`localStorage` は画面確認用であり、会員情報や学習履歴を安全に保存する仕組みではありません。本番では認証済みAPI経由でD1へ保存し、資格画像は非公開R2バケットに置いて署名付きURLで審査担当者だけが閲覧できるようにします。

## 料金の基準値

`curriculum-config.js` を料金表示の単一の基準値とします。

- IROHA月額: 2,980円
- IROHA年額: 29,800円
- 一般初回入会金: 50,000円
- セラピスト初回入会金: 30,000円
- 一般再登録費: 30,000円
- セラピスト再登録費: 10,000円
- TAYORI: 月額980円

月額・年額の継続料金は固定方針、入会金と再登録費は将来改定可能な設計です。実際の請求時は、申込時点の金額を契約レコードへスナップショット保存します。

## 本番化の順序

1. Cloudflare Accessとは別に顧客ログイン方式を確定する
2. Google Driveに `DRIVE_SETUP.md` と `drive-folder-blueprint.json` に沿ったフォルダを作成し、制限付き権限を設定する
3. 専用Google CloudサービスアカウントとDrive APIを用意し、秘密鍵をWorker Secretへ保存する
4. D1へ `20260911_curriculum_foundation.sql` と `20260911_curriculum_drive_delivery.sql` を検証環境から順番に適用する
5. Stripeの商品・価格・Checkout・Customer Portal・Webhookを接続する
6. 非公開R2バケットと資格審査フローを接続する
7. 学習API、権利判定、進捗同期を実装する
8. テスト購入、解約、TAYORIへの変更、再登録、資格画像削除を通しで検証する
9. 承認後に公開ナビゲーションへ追加する
