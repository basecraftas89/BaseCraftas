# ToToNoE+ IROHA

有料学習サービスIROHAのローカルUI・データ設計プロトタイプです。既存の公開コンテンツページとは分離し、公開ナビゲーションからはリンクしていません。

## 現在できること

- 会員ダッシュボードを「学習進捗」「目標設定」「カリキュラム」「学習履歴」の4画面で切り替える。左端の学習進捗には週間学習プランと実績をまとめる。URLの `?view=` で直接開け、戻る操作にも対応し、旧 `?view=plan` も学習進捗へ表示する
- 公開済み動画レッスンを完了すると修了バッジを、同じカリキュラムの公開済みレッスンをすべて終えるとプレビュー修了証をブラウザ内に保存する。未公開教材や学習時間だけの記録では発行しない。別端末同期と公式発行は未対応
- カリキュラムは「分野 → カリキュラム → レベル・モジュール → レッスン」で表示する。分野はAIリテラシー、LLM・対話AI、画像生成AI、動画生成AI、導入・初期設定、組織導入・提案、業務自動化、その他。ツールは任意で、新しいツールやツールを使わない講座も登録できる。未公開の講座名と教材は会員画面に出さない
- 分野一覧はデスクトップで4列、狭い画面では2列・1列に切り替える。学習履歴には8分野の修了バッジ背景と既存公式キャラクターを組み合わせた見本を表示し、取得済みバッジとは区別する。新しいレッスンには分野に応じた同じデザインを自動適用する
- 今週の目標と理由を目標設定画面で保存し、従来の週次レビュー・次週目標とは分けて管理する。公開済みでない教材は開始ボタンを出さない
- 公開案内の価格は職種共通。旧プレビューの職種切替は販売導線に使用しない
- 日曜始まり・土曜終わりの週間学習プランを表示する
- 土曜日に次週の予定が未設定なら、2〜3日の選択を必須ポップアップで案内する
- 1週間の総学習時間を先に確定し、その後に曜日を2〜3日選び、曜日ごとの時間を1分単位で配分してブラウザ内に仮保存する
- 曜日選択時は「総時間 ÷ 選択日数」の1日目安を表示し、時間配分画面では均等案から自由に比重を変更できる
- 学習実績を1分単位で記録し、週の予定時間に対する進捗を表示する
- 土曜日は「今週の実績・学び・障害」を振り返り、SMARTな次週目標とIf–Then実行プランを保存してから次週計画へ進む
- 学習時間と週次レビューはマイページに履歴として蓄積し、旧ORID記録も読み取り専用で表示する
- Drive動画URLからファイルIDを抽出し、分野・カリキュラム名・任意のツール・レベル・公開範囲・制作状態と一緒に教材台帳へ仮保存する。既存のツール別教材は読み取り時に分類する
- Driveの実フォルダは分野を最上位にし、LLM配下にChatGPT・Claude・Geminiを配置した。ローカル台帳へ登録したDrive動画ファイル名の先頭番号で、レッスン一覧と前後移動を数値順にする。公開登録時は同じ講座内の番号重複を拒否する
- 公開時は動画登録・公開権利・対象会員での閲覧確認を必須にする
- 受講中に動画とメモを並べて表示し、メモ欄を開閉できる。学んだこと・疑問点（任意）・次に試すことをブラウザへ下書き保存する
- 動画終了の確認とアウトプット保存を次のレッスンの解放条件とする。旧式の自己申告による完了記録は解放・バッジ判定に使わない。現在のDrive埋め込みでは再生終了を取得できないため、下書きのみ可能で完了操作は無効
- レッスン開始・完了、分野別カリキュラム選択の画面を確認する
- D1向けの会員・契約・資格確認・学習進捗スキーマを確認する
- 相談特典を法人研修プラン公開後に解放し、担当者の30分枠へ接続する構造を確認する
- メール認証後にStripeテストCheckoutへ進み、WebhookからD1へ契約・権限を反映する
- セラピスト資格画像を非公開R2へ提出し、管理者が承認または再提出を依頼する
- 審査結果をResendで申請者へ通知し、審査完了30日後に資格画像を削除する

## 料金の基準値

`curriculum-config.js` は旧プレビューの表示値です。販売時の金額は `apps/tsuzuri-studio-api/src/billing.js` を基準とし、StripeのPriceと一致させます。IROHAの新規Checkoutは現在停止中です。

- IROHA月額: 2,980円
- 職種共通の初回入会金: 0円
- 職種共通の再入会金: 0円
- 初回クーポンの無料期間はIROHAの初回契約履歴をサーバー側で確認してから適用する。TAYORIの契約履歴はこの判定に含めない
- 初回クーポンを適用した場合に限り、月額料金は申込時から3暦月無料。クーポンなしの初回は30日無料、再入会は無料期間なし
- TAYORI: 月額980円

お支払いは月額2,980円のみです。入会金・再入会金・年額プランはありません。実際の請求時は、申込時点の金額を契約レコードへスナップショット保存します。

## 本番化の順序

### 受講メモ（2026-10-03：本番接続済み・IROHAサービス開始前）

- 管理用の [IROHA 受講メモ管理](https://docs.google.com/spreadsheets/d/10y6Je_v1Imt5OX-wj25jZDuCDLyWaAtGo9CwKYplOxs/edit) を作成済み。既存の管理フォルダに配置し、運営メンバーと自動転記用サービスアカウントがアクセスできる。公開リンク共有は設定していない。
- ログインした会員IDとレッスンIDでD1にメモを保存する。ブラウザ内の別会員の下書きは読み込まない。「学習履歴 → 受講メモ」で本人の最新メモを後から確認できる。
- 入力が4秒止まると自動保存し、手動保存も可能。学んだこと・疑問点・次に試すことの更新履歴は管理シートに蓄積する。シート転記失敗時もD1の保存は維持し、定期処理で再送する。
- 同時編集時は入力を保持して競合を表示する。管理シートは行の並び替えを防ぐため保護し、絞り込みはフィルタ表示を使用する。
- `20261002_iroha_lesson_notes.sql` を本番D1へ適用し、API・会員画面を限定反映済み。未ログインの保存APIは401、会員画面はログインへ転送されることを確認。認証した運営アカウントで「接続確認用」メモを保存し、管理シートの実データ行、学習履歴からの再表示、受講画面での復元まで2026-10-03に確認済み。`file://` とlocalhostは画面確認用でブラウザ保存を使用し、実シートへ送信しない。

### 動画の順序受講（2026-10-03：本番接続済み・一般提供は停止中）

- Google Driveを保管先とし、会員権限を確認したAPIからRange対応で配信する。DriveファイルIDを会員へ渡さず、動画の本体をWorkerメモリへ一括読み込みしない。
- 15秒ごとに再生位置をD1へ保存する。サーバーの経過時間と連続した再生範囲を確認し、視聴済み区間へ戻る操作は許可する。最大2倍速まで対応し、長い通信切断は再接続を必要とする。最後までの視聴記録と、本人の「学んだこと」「次に試すこと」の保存が揃った場合だけ完了し、次の動画を開放する。
- 次の動画のURLへ直接アクセスしても、一覧・配信・完了APIは前のレッスン完了を必要とする。端末を変えた場合も保存済み位置から再開できる。メモは開閉でき、疑問点は任意。
- `20261003_iroha_playback.sql` の配信台帳と進捗テーブルを本番へ追加済み。正式教材は明示的に台帳へ承認登録するまで配信しない。Drive自動同期と教材管理画面の本番接続は別途必要。
- `IROHA_ENROLLMENT_ENABLED=false` を維持しており、サービス開始前は運営以外へ教材を配信しない。運営専用の [Claudeフォルダの動画・メモ確認画面](https://basecraftas.com/projects/totonoe/IROHA/lesson.html?preview=claude) は、以前指定された動画だけを確認用に登録する。正式なClaude教材や修了バッジには含めない。
- 視聴記録は通常のスキップを防ぐための制御であり、利用者が画面へ注意を向けていたことを証明するものではない。
- 追加の有料動画サービス契約は不要。既存のWorkers・D1・Driveを利用するため無料枠で着手可能だが、実際の費用は既存プランと利用量に依存する。[Workersの上限](https://developers.cloudflare.com/workers/platform/limits/)、[D1料金](https://developers.cloudflare.com/d1/platform/pricing/)、[Drive利用上限](https://developers.google.com/workspace/drive/api/guides/limits)を基準に運用する。
