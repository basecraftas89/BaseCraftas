# Google Drive教材配信の運用手順

## 1. ルートフォルダを作る

作成済みの [IROHA教材フォルダ](https://drive.google.com/drive/folders/1VhRIwnuJaNr3ATLyWpqbm2oLxS3_aX5T) を起点にする。最上位10フォルダと、6つのカリキュラム内の共通4フォルダは作成済み。ツール系は `02_ChatGPT`、`02_Claude`、`02_Gemini`、`02_Excel・マクロ`、`02_その他AIツール` のように `02_` へ統一する。`01_` は生成AIリテラシー、`03_` 以降は業務別・職種別の非ツール系カリキュラム用に予約する。

教材フォルダは `{カリキュラム}/{区分}/{区分番号}_{講座番号}_{講座名}` とする。例: `02_ChatGPT/01_基礎/01_01_ChatGPTとは何か`。中のファイルは `01_動画.mp4`、`02_文字起こし.pdf`、`03_ワークシート.pdf` とする。

## 2. 共有権限を分ける

- 管理者: ルート全体を管理
- 制作者: `90_制作・確認中` のみ編集
- IROHA有料会員: `01_配信用コンテンツ` のみ閲覧
- 無料体験者: `02_無料体験コンテンツ` のみ閲覧
- TAYORI会員: IROHAのDrive権限を付与しない

すべて「制限付き」を起点にし、「リンクを知っている全員」は使用しない。現在のルートフォルダには「リンクを知っている全員・閲覧者」が残っているため、有料教材をアップロードする前に必ず解除する。

## 3. 教材を制作する

`90_制作・確認中/{ツール}/{レベル}/{教材コード}` に動画・文字起こし・ワークシートを入れる。教材管理画面へ各ファイルURLを登録し、公開前チェックを完了する。

## 4. 公開する

承認後に対象教材フォルダを `01_配信用コンテンツ` へ移し、教材管理画面の配置先を「配信中」、状態を「公開」にする。無料体験は `02_無料体験コンテンツ` へ移す。

## 5. 差し替え・削除

差し替え前の版は `91_差し替え前`、削除候補は `99_削除予定` へ移す。教材管理画面の「削除」は台帳だけを削除し、Driveファイルは削除しない。

## 本番接続に必要なもの

1. Google CloudプロジェクトとDrive API
2. 専用サービスアカウント（秘密鍵はCloudflare Worker Secretへ保存）
3. 対象Driveフォルダをサービスアカウントへ共有
4. D1マイグレーションの適用
5. 管理者APIでAccess JWTと管理者権限を検証
6. 会員の契約状態とDrive権限の付与・失効を同期

ローカル画面の保存内容はブラウザのlocalStorageだけであり、会員保護や共有権限の根拠には使用しない。
