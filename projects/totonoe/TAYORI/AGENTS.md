# TAYORIのサービスのお知らせ

- TAYORI会員の使い方・仕様・受付条件・表示を更新して本番反映する際は、同じ作業で `guide-content.json` の `news` に日付、短いタイトル、会員向けの説明を追加する。
- 日付は本番反映日（日本時間）の `YYYY-MM-DD`。新しい記事は配列の先頭に追加する。同一日の記事も追加した順で表示される。
- 書く内容は「何が変わったか」「どこから使うか」「会員がすること」。短い1〜2段落で記載し、必要のない技術情報・内部設定・個人情報は掲載しない。
- 未反映の変更を公開済みとして記載しない。反映後にご案内のお知らせ表示を確認する。ローカルだけの検討は公開記事へ追加しない。
- フォームの `contact_url` と既存記事を保持する。記事の本文はHTMLではなくプレーンテキスト。
- 更新例: `{ "date": "2026-10-04", "title": "活用動画にサムネイルを追加しました", "paragraphs": ["ご案内の動画からサービスの使い方を確認できます。"] }`
