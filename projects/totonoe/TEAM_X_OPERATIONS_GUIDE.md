## 2026-10-03追記：プロフィール設置と投稿形式の運用（共有Sheets反映済み）

- 現在の「SNSリンク一覧」はX・Instagram・Facebook・noteの媒体別固定リンクを掲載。各リンクの右に「プロフィール設置済み」チェックを追加した。本人が現在の設置を確認してチェックする。未チェックは未確認を含み、未設置の確定数ではない。チェックは初期未記入・未チェックで、本人のSNSを変更していない。
- 「SNS広報投稿記録」の左側を `担当者｜SNS投稿URL｜媒体｜掲載形式｜リンク案内` に整理。日時・切り口・案内先・振り返りは右側の任意欄に保持。紹介投稿後、本人が担当者・URL・形式・案内を記録し、媒体も選ぶ運用。チャットとシートへの二重報告は求めない。
- 掲載形式は「通常投稿／返信・コメント／ストーリーズ／リール・動画／その他」。リンク案内は「専用リンクを直接掲載／プロフィールの専用リンクへ誘導／リンク案内なし」。通常投稿からプロフィールへ誘導した場合も、両者を別項目として記録する。
- 「SNS広報ダッシュボード」は、HP訪問の週次集計とは別に、現在のプロフィール設置報告人数、全期間の掲載形式・案内別の記録件数、未分類件数を表示する。日付フィルターはHP訪問の週次・媒体集計だけに適用し、投稿内訳は全期間、設置状況は現在の自己申告。順位・個人評価には使わない。
- 設置数・投稿件数は訪問数ではない。同じ媒体固定リンクを共用するため、プロフィール／投稿／ストーリーズ別の訪問数や成果は分離できない。設置場所別リンク、GA4自動同期、CTA完了計測は今回追加していない。
- チェック複数媒体の同一人重複除外、形式・案内の件数と未分類、週次55セッション・媒体55セッションのグラフ描画、空欄への復帰と再入力追随を検証した。一時検証入力は全除去し、実績は未記録に戻した。

以下の旧「投稿URLだけをチャットで共有」案より、この共有Sheets運用を優先する。

## チームへの共有文（この節をそのまま送れます）

ToToNoE+を紹介したい方には、下の**自分専用リンクを1本だけ**お渡しします。Xのプロフィールにも、ToToNoE+を紹介する投稿にも、同じリンクを使ってください。投稿のたびにリンクを作ったり、管理者に発行を依頼したりする必要はありません。毎週の投稿義務もありません。

紹介投稿をしたときだけ、既存のチーム連絡場所に**Xの投稿URLを1本貼ってください**。日時・テーマ・数字の入力や、別のシートへの転記は不要です。投稿の内容を読み解く作業は、分析担当が週1回まとめて行います。

チームの皆さんにお願いするのはここまでです。GA4やLINEの管理画面への登録、数字の集計、SNSアカウントの連携は不要です。数字を個人の順位・評価には使いません。「どんな悩みを、どう言い換えた発信がサイト訪問につながったか」を学ぶために使います。

最初に使う前に一度開き、ToToNoE+のトップが表示されることを確認してください。リンク先の計測情報はサイト側で付けるので、各自でURLを編集する必要はありません。プロフィールの既存リンクを置き換えにくい場合は、紹介投稿でだけ使っても構いません。

## 計測担当の最小運用

1. 各自の使用希望を確認して公開済みのリンクを1本ずつ渡す。以後、投稿ごとのリンク発行・短縮URLの追加・サイトの再デプロイはしない。
2. 紹介投稿をした本人から、**投稿URLだけ**共有してもらう。集約先は既存のチーム連絡場所を一つに決め、新しいツール・フォーム・シートへの二重入力は求めない。小島が週1回まとめて投稿を開き、日時・内容を確認し、必要な投稿だけGrokで分析する。神藤による投稿ID発行・日々の転記は不要。
3. 週1回、GA4で `utm_source=x`、`utm_medium=organic_social`、`utm_campaign=totonoe_team` のサイト到着**セッション数**を確認し、合計と `utm_content` 別の7名分を記録する。同じ人の複数訪問は複数セッションになり得るため「訪問人数」とは呼ばない。
4. 投稿前後の変化を見ながら「どの悩み・言い換え・案内が反応につながりそうか」を仮説として振り返る。1人のリンクをプロフィールと複数投稿で共用するため、**GA4の数字だけで特定投稿の訪問数・成果とは断定しない**。
5. 既に配布した旧形式の `_profile_team-profile` リンクが実際に使われていた場合、集計時はその分も該当メンバーに含める。設置状況は未確認なので、移行前に本人へ確認する。

## この方式で分かること／分からないこと

| 見たいこと | 1人1リンクでの扱い |
| --- | --- |
| X専用リンク経由のHP訪問合計 | GA4のタグ付きセッションとして集計できる。Xからの全訪問数ではない。 |
| メンバー別のHP訪問 | `utm_content` で集計できる。個人の評価・順位付けには使わない。 |
| どの投稿の後に動きがあったか | 投稿URL・日時の記録と週次／日次推移を並べて**傾向を考える**。プロフィールからの流入や他投稿の影響を分離できない。 |
| その投稿が何件の訪問を生んだか | **正確には分からない**。投稿別の厳密な識別には投稿別リンクが必要だが、当面は運用負荷を優先して採用しない。 |
| TAYORI・セミナー・LINEへの到達や申込 | それぞれのCTA・完了計測が公開・検証されてから追加する。現時点で成果実績とは呼ばない。 |

投稿の良し悪しを判断するときは、到着数だけでなくX上の表示数・反応・リンククリック数（本人が任意で共有できる場合）や投稿内容も見る。比較対象の投稿が重なった週、リンクの再共有、計測拒否、別端末での再訪などでは因果関係が曖昧になる。最初の1〜2か月は目標値やランキングを置かず、記録を貯めて「次に試す切り口」を決める。

### 投稿記録を楽にする方法（推奨案）

**メンバーの必須入力は投稿URLのみ。** 共有先は既存のチーム連絡場所の1スレッド等を使い、紹介投稿後にURLを貼るだけにする。URLから投稿者を、投稿画面から公開日時・本文を確認できる。共有メッセージの日時を投稿日時の代わりにはしない。

- 小島の週次記録は `週｜X専用リンク経由セッション合計｜メンバー別セッション｜注目した投稿URL｜次に試すこと（1行）` に絞る。全投稿のテーマ分類は必須にしない。
- 注目した投稿だけ「対象の悩み・言い換え・案内先」を読み解く。表示数・反応数は本人が任意で共有できる場合に補足する。
- **さらにメンバーの報告をなくす案**：小島が週1回、対象アカウントの公開投稿をまとめて確認する。ただし見落とし・削除・閲覧制限があり、Grokによる全投稿の漏れない自動取得は保証できない。収集工数が小島に移るため、まずはURL共有が現実的。
- 投稿ログの完全自動収集・自動転記は未実装。最小運用には新しい有料サービスやX API連携を使わない。Grokの利用可否・料金は小島側の契約に依存し、無料運用の必須条件にはしない。

この記録は投稿内容と訪問推移を並べて仮説を考えるためのものであり、各投稿にGA4の訪問数を自動で割り当てるものではない。複数投稿・プロフィールの影響が重なるため、施策の厳密な因果効果ではなく傾向として共有する。

## 無料枠と、今できる範囲

**結論：必須の「X専用リンク経由のHP訪問合計」と「担当者別の訪問」は、標準GA4と上のURLで追加の有料契約・X API連携なしに運用可能です。短縮リンクからGA4へのUTM付き受信まで確認済みです。標準レポートでのメンバー別セッション集計は別途確認が必要です。**

- 公開中のToToNoE+トップにはGA4タグ `G-1SK6NEFC8V` が設置されています。Google公式資料によると、標準GA4は無料で、URLの `utm_content` を「セッションの手動広告コンテンツ」として扱えます。7名分のURLだけを用意しても、訪問がなければ数値は増えません。
- X投稿の表示数、投稿内リンククリック数、投稿ごとの真の貢献、後日の別端末での申込みまでは、この方法で自動判定できません。リンクの再共有や計測拒否でも数字はずれます。「Xから来た人の全数」ではなく「この専用リンクで計測できたセッション」として扱います。
- 既存のCloudflare側の流入画面はX全体の概況に使えますが、UTMを記録しないため担当者別集計には使いません。GA4のUTM数とCloudflareのX参照元数を足しません。
- TAYORI・セミナー・LINEボタンのクリック／申込完了の連結は**次段階**です。現時点で公開済みの計測結果として扱いません。専用ダッシュボードの自動集約も未実装で、最初はGA4画面と週次記録で十分です。
- 公式LINEはアカウント・導線ができてから別途設計します。LINE公式アカウントのコミュニケーションプランは月額0円、無料メッセージ月200通、追加配信不可です。ただし友だち追加経路の詳細は最大90日、経路ごとの追加が20件未満だと詳細値が表示されないため、少数期に「X直行／HP経由」の正確な内訳を約束できません。

## 計測開始前の確認

- 計測担当が自分の専用リンクを実際に開き、公開ページが表示され、UTMが消えないことを確認する。
- GA4でのUTM付きテスト訪問のリアルタイム受信は確認済み。次に、標準レポートの「セッションの手動広告コンテンツ」でメンバー別セッションが表示されることを確認する。リアルタイムのページビュー数を週次の訪問セッション数に置き換えない。
- 本人の同意を得てリンクを配布・掲載する。こちらから本人のXプロフィールや投稿を勝手に変更しない。
