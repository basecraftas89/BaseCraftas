# Column Studio

Base Craftas / ToToNoE+ のコラムを、WordPressのような管理画面から編集するためのフロントエンド試作です。

## 現在できること

- 記事一覧、検索、公開状態フィルター
- 新規作成、下書き保存、公開状態への変更
- 太字、下線、マーカー、見出し、箇条書き、引用、リンク
- ミオン、ツグモ、ハクト各5種類の表情による吹き出し挿入（丸アイコンの下に専用名札を表示）
- 記事プレビュー
- 管理者、編集者、閲覧者それぞれの画面確認
- メンバー招待と権限変更の操作確認
- ブラウザ内の自動保存

## 保存と権限について

この版は画面と編集体験を確認するための試作で、記事とメンバー情報はブラウザの `localStorage` に保存されます。ブラウザ内保存だけでは、複数人での共有や安全な権限制御にはなりません。

本番で複数人が利用する際は、次の接続が必要です。

1. メールまたはGoogleアカウントによるログイン認証
2. 記事、メンバー、キャラクター画像を保存するデータベース／ストレージ
3. 管理者・編集者・閲覧者をサーバー側で検証するアクセス制御
4. 公開操作で静的サイトの記事データを更新するAPIまたはビルド連携

認証なしの状態で、この管理画面を公開URLからアクセス可能にしないでください。
