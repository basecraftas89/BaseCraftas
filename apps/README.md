# Apps

This directory is reserved for future Base Craftas web apps, demos, and
diagnostic tools.

Use one directory per app:

```text
apps/
└─ example-tool/
   ├─ index.html
   ├─ styles.css
   └─ script.js
```

Keep primary service pages in `services/` and representative-led project sites
in `projects/`.
