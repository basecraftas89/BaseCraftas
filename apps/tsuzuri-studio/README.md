# ToToNoE+ Studio

つづり｜TSUZURIと動画コンテンツを編集・公開する管理画面です。Podcastとアーカイブ動画はスタジオ外で管理し、メニュー・一覧・新規作成には表示しません。既存の保存データと公開ページは保持します。

## 使い方

- つづり｜TSUZURI：新規作成からタイトル、Main Actor、本文を入力します。note URLからの情報取得、画像、会話の吹き出しも利用できます。
- つまみ｜TSUMAMI：左メニューから新規作成し、YouTube動画のURLとタイトルを入力します。情報取得が失敗した場合も手入力と画像アップロードで補完できます。動画ファイル本体のアップロードは行いません。
- 下書き保存後、管理者が公開します。「GitHub更新済み」と実サイトへの反映確認は別の段階として表示します。
- 本番ではCloudflare AccessとAPIに接続します。ローカルの端末版はブラウザ内保存のみで、公開できません。

## 障害の切り分け

記事の読み込みはアーカイブ同期・資格申請・メンバー一覧に依存しません。資格申請とメンバーはそれぞれの画面を開いた際に取得します。操作権限不足（403）で編集中の記事を消去せず、認証切れ（401）は再ログインが必要です。

## 検証と反映

`npm test` で保存、競合、履歴、画像、公開用HTML/JSON、権限と起動時の障害分離を検証します。本番反映には静的サイトのビルド・デプロイが必要です。ローカルテスト成功は本番の認証・DB・GitHub接続や公開確認を保証しません。
